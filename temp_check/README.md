# RenewWise

RenewWise helps you check which household bills, subscriptions, insurance policies, and warranties need attention. Ask it to search a NAS folder you authorize and give it a date window. It returns a sorted list with the source document and evidence for each date, while flagging anything ambiguous for you to check.

The Round 1 prototype is read-only. It does not create reminders, move or change files, or send document content outside the NAS. See [SKILL.md](SKILL.md) for the full workflow, capability boundaries, and failure handling.
